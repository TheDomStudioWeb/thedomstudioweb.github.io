DOM Calendario

Política de privacidad

Última actualización: 16 de octubre de 2026

DOM Calendario es una aplicación de The DOM Studio Web (Mendoza, Argentina) que muestra en una sola pantalla los eventos de Google Calendar del usuario: vistas de día, semana y mes, y una agenda con cuenta regresiva. Esta política explica qué datos usa la aplicación y cómo los protege.

En resumen: DOM Calendario solo lee tus calendarios para mostrártelos en tu propio dispositivo. No guarda tus datos en servidores, no los comparte ni los vende, y The DOM Studio Web no tiene acceso a ellos.

Qué datos usa

Cuando conectás una cuenta de Google, la aplicación solicita estos permisos:

  • Ver tus calendarios (calendar.readonly): lista de calendarios y eventos con título, fecha, hora, ubicación y color. Es de solo lectura: la aplicación no puede crear, modificar ni borrar eventos.
  • Información básica de la cuenta (mail, nombre e imagen de perfil): solo para identificar cada cuenta dentro de la aplicación y permitir cambiar entre ellas.

Cómo los usa

  • Los eventos se descargan directamente desde Google al dispositivo del usuario y se usan únicamente para mostrarlos en pantalla.
  • Se guarda en el mismo dispositivo una copia de los últimos eventos, para poder mostrarlos sin conexión a internet.
  • No se usan con fines publicitarios, de análisis ni de perfilado, y no se usan para entrenar modelos de inteligencia artificial.

Dónde se guardan

Todo queda en el dispositivo del usuario. Las credenciales de acceso de cada cuenta se guardan cifradas con la protección del sistema operativo (en Windows, la protección de datos del usuario de Windows). DOM Calendario no tiene servidores propios: The DOM Studio Web no recibe, almacena ni puede consultar los datos de calendario de ningún usuario.

Con quién se comparten

Con nadie. La aplicación solo se comunica con los servicios de Google necesarios para iniciar sesión y leer el calendario.

Uso de datos de las API de Google

El uso y la transferencia de información recibida de las API de Google por parte de DOM Calendario se ajustan a la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo quitar el acceso y borrar los datos

  • Dentro de la aplicación: Ajustes › Cuentas de Google › quitar la cuenta. Se revoca el acceso y se borran del dispositivo los datos de esa cuenta.
  • Desde Google: en myaccount.google.com/permissions, quitando el acceso de DOM Calendario.
  • Al desinstalar la aplicación se eliminan sus archivos. Los ajustes guardados en la carpeta del usuario pueden borrarse manualmente o a pedido.

Menores de edad

DOM Calendario no está dirigida a menores de 13 años y no recopila datos de manera intencional sobre ellos.

Cambios en esta política

Si esta política cambia, se publicará la nueva versión en esta misma página con la fecha de actualización.
