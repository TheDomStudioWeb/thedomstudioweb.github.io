# Manual interno · Catálogo de demos de The DOM Studio Web (para Claudio)

## Qué es
Una página con todas las demos que se pueden probar sin cuenta, desde el celular y con datos inventados: https://thedomstudioweb.github.io/demos/

| Demo | Para quién | Cómo entrar |

## Cómo funcionan las demos de DOMino
- El botón «Probar la demostración» solo aparece si la dirección del ingreso termina en `?demo`. Los clientes reales no lo ven.
- En demo no se conecta a ningún servidor: usa una base local con datos de un negocio ficticio (Estudio Altamira, Alma Animal, Vita Aura Bienestar).
- Lo que se carga queda solo en ese dispositivo. La barra dorada de abajo dice «Demostración» y tiene «Reiniciar» para volver a los datos de ejemplo.
- Al salir de la cuenta se termina la demo.
- En la demo de Veterinaria y Bienestar no se muestra la agenda de turnos online (usa un servicio externo real). Se puede ofrecer una demostración aparte.
- En la demo, el módulo de documentos está activo para que se vea cómo funciona; en las cuentas reales depende de que el cliente tenga activo el almacenamiento de archivos.
